# Learn the tools

One short guide per tool. Each one says **what it is**, **where this API uses it**, and **how to use it**, with examples taken from the kit's own code.

Read them in this order if the stack is new to you:

| # | Guide | In one line |
| --- | --- | --- |
| 1 | [PHP and Composer](01-php-and-composer.md) | the language, and how libraries are installed |
| 2 | [Laravel basics](02-laravel-basics.md) | routes, controllers, requests, middleware, `.env` |
| 3 | [Validation](03-validation.md) | checking input with rules |
| 4 | [Eloquent models](04-eloquent.md) | reading and writing the database with PHP |
| 5 | [Migrations and seeders](05-migrations-and-seeders.md) | creating tables and demo data |
| 6 | [Passport and sign-in](06-passport-auth.md) | tokens, the cookie, the signed-in user |
| 7 | [Artisan commands](07-artisan.md) | Laravel's command-line helper |
| 8 | [MySQL and Laragon](08-mysql-and-laragon.md) | the database and the local server |
| 9 | [Testing the API (Postman / curl)](09-testing-the-api.md) | calling endpoints without the React app |

How the kit's own code fits together (routes, ResponseTrait, PaginatedListTrait, the Products example) is in the main [README](../README.md).

> Tip: open the file the guide mentions next to the guide and read both together.
